# 양진영 마케팅 포트폴리오 · 미래엔 지원용

## 미리보기

압축을 풀고 `index.html`을 엽니다. 핵심 업무와 주요 성과 사례를 선택하면 해당 상세 내용으로 이동합니다. 이미지는 클릭하여 확대하고, 영상 링크는 새 탭에서 엽니다.

## 기존 포트폴리오와 다른 주소에 게시하기

1. GitHub에서 기존 저장소와 별개로 `work-samples` 이름의 저장소를 만듭니다.
2. 이 디렉터리의 파일을 모두 새 저장소의 루트에 올립니다.
3. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main`, `/ (root)`를 선택합니다.
4. 발행 주소는 `https://<GitHub 사용자명>.github.io/work-samples/` 형식입니다. 실제 주소는 Pages 설정에서 확인합니다.

## 이미 올린 웹 포트폴리오 수정하기

현재 저장소의 사이트 파일을 압축 파일 내용으로 교체합니다. 새 `media/` 폴더를 함께 올리고, 루트에 남아 있는 이전 이미지와 브랜드명이 포함된 기존 이미지 파일은 삭제합니다. 이번 버전의 이미지 경로는 모두 `media/`를 사용합니다.

## 검색 노출 설정

- HTML의 `noindex`와 `noimageindex`는 이를 지원하는 검색엔진에 페이지와 페이지 내 이미지의 검색 제외를 요청합니다. 검색 로봇이 이 지시를 읽을 수 있도록 HTML 경로는 robots.txt에서 막지 않습니다.
- 이미지 파일 자체의 수집 제한에는 도메인 루트의 `https://<사용자명>.github.io/robots.txt`가 필요합니다. 프로젝트 주소 아래의 `robots.txt`는 효력이 없습니다. 도메인 루트에 다른 사이트도 있다면 기존 robots.txt에 `Disallow: /<포트폴리오-저장소명>/media/`만 해당 사용자 에이전트 그룹에 추가해 범위를 한정합니다.
- 이미 등록된 주소가 있다면 검색엔진의 삭제 요청 도구를 사용합니다. 공개 URL을 아는 방문자는 페이지와 이미지에 접근할 수 있습니다.

## 제출 전 확인 항목

- 윈터스쿨 문구는 요청서 기준입니다. 실제 집행 소재의 최종 카피와 확인해 주세요.
- 사례 04의 광고비 절감률, 모집 인원당 광고비 절감률, 모집 인원 증가는 제공값입니다. 같은 모집군·기간으로 계산한 수치인지 확인이 필요합니다.
