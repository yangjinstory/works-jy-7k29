# 양진영 마케팅 포트폴리오 · 미래엔 지원용

## 미리보기

압축을 풀고 `index.html`을 엽니다. 핵심 업무와 주요 성과 사례를 선택하면 해당 상세 내용으로 이동합니다. 이미지는 클릭하여 확대하고, 영상 링크는 새 탭에서 엽니다.

## 기존 GitHub Pages 사이트에 반영하기

1. 직전 최종 수정본을 배포했다면 `cases.js`만 교체합니다.
2. 전체 사이트를 처음 배포한다면 코드와 `media/` 폴더를 함께 올립니다.

## 이미지 파일 자체 수집 제한

1. 압축에 포함된 `robots.txt`를 사용자 사이트 저장소 `yangjinstory.github.io`의 게시 루트에 적용합니다. 기존 파일이 있다면 내용을 유지하고 `Disallow: /works-jy-7k29/media/`를 해당 크롤러 그룹에 추가합니다.
2. 배포 후 `https://yangjinstory.github.io/robots.txt`에서 규칙을 확인합니다. 크롤러는 도메인 루트의 파일을 읽습니다.
3. HTML은 크롤러가 `noindex`와 `noimageindex`를 읽을 수 있게 열어 둡니다. 규칙을 따르는 크롤러의 이미지 수집에 적용되며, 방문자는 이미지 URL을 열 수 있습니다.

## 제출 전 확인 항목

- 윈터스쿨 문구는 요청서 기준입니다. 실제 집행 소재의 최종 카피와 확인해 주세요.
- ‘광고 개편을 통한 광고 효율 개선’ 사례의 12%는 전년 대비 광고를 통한 유입 증가율입니다.
